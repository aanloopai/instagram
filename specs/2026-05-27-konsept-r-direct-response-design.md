### Visual signature

- **Oxblood/burnt-orange seamless backdrop** (~#a0301a) — match Aanloop brand accent
- **Hardcoded burned-in subtitle** (1 phrase/time, beyaz outline)
- **3 visual mode interleave:**
  1. Talking-head (medium close-up, oxblood BG)
  2. White grid-paper "ruled note" slide (bold black + 1 blue accent + icon)
  3. Floating product UI screenshot (lifted from laptop, soft shadow)
- **Whip-pan motion-blur transitions** (~0.4s between major beats)
- **Final CTA = white card**, bold sans, 1 blue accent word, black pill button

Hook → Brand reveal → Product proof → Guarantee → Mechanism → Stat
     → Offer → Specificity → Scarcity → Case study → Result → Social proof → CTA

## 4. Production pipeline (Google Veo 3 omni)

### Approach

Veo 3 omni mode = native audio + lip-sync 8s shot. 17 beat = ~7 talking-head shot (Veo 3 8s × 7 ≈ 56s talking-head) + 5 slide composite + 3 UI shot.

### Step-by-step

1. **Imagen 4 — narrator portret (NL-male IT-expert, photoreal)**
   - Tek-shot prompt: `prompts/imagen/konsept_r_narrator.txt`
   - Generate: frontal (master), 3/4 left, 3/4 right, profile left, wider (5 angle)
   - Per angle 6-10 varyant, M sec best
   - Oxblood seamless BG #a0301a, white T-shirt, lavalier mic visible, age 32-36
   - QA gate: 5-kisi blind test "AI mi gercek mi" — %80+ "gercek"
   - Output: 5 PNG @ 1080×1920
   - Path: `assets/characters/narrator/`

2. **Veo 3 omni image-to-video — speaking shots (7 shots × 8s)**
   - Input per shot: Imagen 4 narrator PNG (reference_image) + NL VO transcript + duration 8s
   - Veo 3 omni: native audio + auto lip-sync, frontal reference locked
   - Per-shot prompt: `prompts/veo3-i2v/shot_##.txt` (Fase 1'de yazilacak)
   - Identity-consistency check: 7 shot arasinda yuz tutarli mi? Yoksa same-seed re-roll
   - Shots:
     - Shot 1 (0:00-0:08): Hook + bridge (segments 1-2)
     - Shot 2 (0:09-0:16): Brand reveal + product proof intro (3-4)
     - Shot 3 (0:15-0:23): Guarantee tease + risk-reversal echo (5)
     - Shot 4 (0:24-0:34): Mechanism + proof stat (7-8)
     - Shot 5 (0:35-0:42): Offer reveal + open loop (9-10)
     - Shot 6 (0:52-1:02): Case study + result stat (13-14)
     - Shot 7 (1:03-1:14): Social proof + CTA bridge + CTA card setup (15-17)
   - 9:16 1080×1920 24fps
   - Path: `assets/video/konsept_r/veo3/`

3. **Imagen 4 — grid-paper slide assets**
   - Static white grid background
   - 5 slide content:
     1. Risk-reversal "Dan krijg je elke euro terug." (blue text)
     2. Specificity "De eerste 20 MKB'ers" + buildings icon
     3. Specificity 2 "drie grootste AI-kansen" + EUR icon
     4. Urgency "Wees er snel bij" (red accent)
     5. CTA card "Claim nu jouw gratis AI-Readiness Scan / [CLAIM NU]"
   - DaVinci Fusion: animated text reveal + grid texture
   - Path: `assets/video/konsept_r/slides/`

4. **Product UI screenshots — Marco/Emma dashboard**
   - Lift from existing aanloopai.nl/marco + /emma landing screenshots
   - Photoshop: rotate slight, soft shadow, transparent BG
   - 3 UI shots: Marco dashboard, Emma chat balon, ROI-calculator
   - Path: `assets/video/konsept_r/ui-shots/`

5. **ElevenLabs — VO backup**
   - Veo 3 omni-audio quality ilk test. Yetersizse ElevenLabs NL voice + DaVinci mux.
   - Voice: Aanloop'in mevcut NL female voice (Konsept A icin secilen)
   - Path: `assets/audio/vo/konsept_r/`

6. **DaVinci Resolve — assemble**
   - 9:16 1080×1920 24fps timeline
   - 7 Veo 3 talking-head + 5 grid slide + 3 UI screenshot = 15 cut total
   - Hardcoded subtitle: Fairlight DaVinci Subtitles, white outline + drop shadow, 1 phrase animation
   - Whip-pan transitions (0.4s motion blur via Fusion)
   - Color grade: oxblood backdrop boost + warm bone overlay
   - Music: Suno bed_music 25s × 3 loop
   - VO foreground -8dB, music -22dB sidechain
   - Master: H.264 25Mbps, -14 LUFS, -1 dBFS peak
   - Path: `assets/output/konsept_r_master_75s.mp4`

- DaVinci assemble: 4-6 saat
